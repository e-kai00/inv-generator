# iGenerator
The app randomly generate list of prices.  

## Features:

- accepts initial ammount in usd and current currency rate in format 10.00 with up to 4 digits after the decimal point;
- on submit ("generate") convert currency and generates a list on prices in format "item name - item price";
- on clear - clears all input fields;
- on download - adds additional info (amount and date) and downloads pdf;
